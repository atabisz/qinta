# Rows are <reason>TAB<normalised line text>TAB<why>. The gate normalises a line by stripping
# leading comment markers and quoting punctuation, collapsing whitespace and lowercasing, so a row
# is keyed on TEXT and never on a line number: in this tree a base-to-current line map was right 7
# times out of 56, and the text moves with the line.
#
# A ROW THAT MATCHES NOTHING IS A FAILURE, not a no-op. This population SHRINKS when the tree is
# fixed -- a correction record gets reworded, a quotation gets closed, a file leaves the manifest --
# so a row that has stopped applying would otherwise sit here reading as though it still excused
# something.
#
# The five reasons, and only these five:
#   correction     the line is part of a correction record, which has to restate a false claim in
#                  order to correct it
#   quotation      the line quotes an old claim that the surrounding text closes and refutes
#   history        a reading taken at a past tree, in the past tense, discharged nearby
#   co-occurrence  the assertive phrase's SUBJECT is not the manifest entry whose basename matched;
#                  most of these are single-line README table rows where the two sit in different
#                  cells
#   true-claim     the claim is about this entry and is true -- reserved, and EMPTY as of
#                  2026-09-22, because the gate's phrase list is deliberately restricted to
#                  claims about COMPILING, which is the only thing manifest membership asserts.
#                  A row landing here is a signal the phrase list has drifted into claims about
#                  linking, where the manifest's compile-only section makes such claims true.
